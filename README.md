# Agarwal Moving Solution – website

Static website for Agarwal Moving Solution (Corporate Relocation & Logistic Experts), Poonamallee, Chennai.
Layout follows a classic packers-and-movers format: top bar, logo + menu + Free Quote button, hero slider,
quote form, welcome/about split, service cards, call-to-action band, why-choose-us list, service areas, and a
detailed footer, plus floating Call/WhatsApp buttons and a mobile quick-contact bar.

- Open `index.html` in any browser to view it.
- `build.py` generates all pages. Edit contact details, services or areas at the top of that file, then run `python3 build.py`.
- Styles: `assets/css/style.css`. Scripts (menu, slider, WhatsApp quote form, gallery): `assets/js/main.js`.
- Quote forms open a WhatsApp message to +91 70158 54009; nothing is stored on a server.
